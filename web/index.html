SUPER ROCKET

EARTH -> MARS

A C game with a 1990s-style web frontend.

TerminalBrowser
make
./super-rocket
make web
./super-rocket-web 8080

Once the C server is running, play locally.

This file is only a launch guide. The C server supplies the live game page.

Enable frames and JavaScript. Click the screen and press Enter.

Arrows or WASD: thrust. Space: fire. P: pause. H: help. Q: menu.

Keep the server local; it has no accounts or encryption.
